# Bank Management System - Frontend Web Application

This directory contains the Angular single-page frontend application for the Bank Management System, styled using Angular Material Design.

## Key Features
- **Modern Angular 17** architecture with Standalone Components.
- **Angular Material Components:** Cards, Tables, Sidenav drawer, Forms, Dialogs, Snackbars, and Loading spinners.
- **Client Services:** Handles secure HttpClient communications, reactive input validation, and localStorage session caches.
- **Security guards:** Functional guards to block unauthorized users, and dynamic HTTP interceptors to attach token authentication headers automatically.

## Getting Started
1. Install project dependencies:
   ```bash
   npm install
   ```
2. Start the local server:
   ```bash
   npm run start
   ```
3. Navigate to `http://localhost:4200/` in your browser.

## Production Build
To compile the production build:
```bash
npm run build
```

For full details, see the main [README.md](../README.md) in the workspace root.
